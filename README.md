# DBMS Lab Experiments (1–7)

## About the Project
This repository contains SQL code and lab manual documentation for Database Management System (DBMS) Experiments 1 to 7. These experiments are part of my academic coursework and help develop practical knowledge of database concepts and SQL operations.

## Experiments Included

### Experiment 1: Basic SQL Operations
Introduction to database operations and basic SQL commands.

### Experiment 2: SQL Queries and Operations
Practice of SQL queries for working with database tables and records.

### Experiment 3: Database Schema and SQL Queries
Creating database tables and performing selection, projection, aggregate functions, grouping, filtering, and sorting operations.

### Experiment 4: Joins and Subqueries
Working with SQL joins, subqueries, EXISTS, set-operation alternatives, and query execution plans.

### Experiment 5: Views and Recursive CTE
Creating and using SQL views, understanding view updatability, and working with recursive Common Table Expressions (CTEs).

### Experiment 6: Stored Procedures and Triggers
Implementing stored procedures, salary validation triggers, and audit triggers.

### Experiment 7: Database Normalization
Understanding normalization from UNF to 3NF and BCNF, including lossless join and dependency preservation.

## Repository Contents
- `DBMS_Experiments_1_to_7.sql` – SQL code for Experiments 1–7.
- `DBMS_Lab_Experiments_1_to_7.pdf` – Lab manual soft copy containing experiment documentation and outputs.
